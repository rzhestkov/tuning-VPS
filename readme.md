# Настройка VPS Ubuntu 24.04

## Быстрый старт

Скрипт рассчитан на свежий VPS Ubuntu 24.04 с доступом `root` по временному паролю и открытым SSH-портом 22. До первого запуска поместите активный публичный ключ `ssh-ed25519` в `ssh/authorized_keys` в репозитории: скрипт получает этот файл по адресу, заданному в `SSH_KEY_URL`.

Подключитесь к новому серверу как `root`, скачайте скрипт и запустите его командой:

```shell
curl -fsSL https://raw.githubusercontent.com/rzhestkov/tuning-VPS/main/setup_ubuntu_24.04.sh -o setup.sh
bash setup.sh
```

Перед запуском при необходимости измените в начале файла `NEW_USER`, `SSH_PORT`, `TIMEZONE`, `GITHUB_USER` и `REPO_NAME`.

Во время первого запуска скрипт попросит подтвердить вход в новом окне как `user1` по ключу на порту `2332`. До этого подтверждения старый доступ сохраняется. После успешной настройки повторный запуск выполняется через `sudo bash setup.sh` из сессии `user1` и безопасно приводит управляемые настройки к целевому состоянию.

Docker устанавливается только после ответа `y` на отдельный вопрос. После установки скрипт отдельно спрашивает, добавлять ли `user1` в группу `docker`; этот доступ эквивалентен правам root.

## Цель и задача

Проект готовит новый VPS для личного безопасного использования.
Цель — безопасная и повторяемая базовая настройка Ubuntu 24.04
DВсоответствии с современныеми понятиями настраивается SSH, j, овления, firewall и другое.

## Что настраивает скрипт

- Обновляет Ubuntu и устанавливает лёгкие инструменты администрирования: файловый менеджер, редактор, средства диагностики процессов, диска, DNS, TCP, JSON и передачи файлов.
- Настраивает временную зону и синхронизацию времени, отключает неиспользуемые системные службы и применяет безопасные параметры ядра. 
- Создаёт административного пользователя `user1`, выдаёт ему sudo и задаёт проверяемые лимиты ресурсов.
- Переводит SSH на вход только по ключу, порт `2332` и запрет root/password-доступа. Конфигурация создаётся в отдельном файле и проверяется с учётом различий конфигураций у хостеров.
- Включает IPv4 UFW с входящим deny и разрешает только SSH. Чужие правила не удаляются и отображаются в отчёте.
- Включает fail2ban и auditd для изменений административной конфигурации. Сетевые соединения, DNS, VPN-клиенты и адреса назначения постоянным аудитом не собираются.
- Включает ежедневные обычные и security-обновления Ubuntu, автоматический reboot при необходимости в 03:00 и автоматический restart затронутых сервисов.
- Ограничивает journald семью днями и 50 MiB; подробный debug-режим включается временно через `sudo tuning-vps-debug-logging enable 30m`.
- По запросу устанавливает Docker, включает для новых контейнеров ограниченную ротацию логов и показывает опубликованные порты. База не устанавливает VPN, proxy, веб-серверы, базы данных или другие приложения.

## Что выводит скрипт

Во время работы выводятся этапы, предупреждения и вопросы, от которых зависит безопасный переход SSH или установка Docker. В конце выводится отчёт с `OK`, `WARN`, `FAIL` и `SKIP`, состоянием SSH, UFW, автоматических обновлений, журналов, Docker и набора административных инструментов.

Скрипт не печатает приватные ключи, секреты приложений, ссылки подключения или подробности пользовательского трафика. Предупреждение требует ручной проверки; обязательная ошибка прекращает опасный участок сценария.
