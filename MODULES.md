# Модули приложений

Основной `setup_ubuntu_24.04.sh` готовит VPS: защищённый SSH-доступ, IPv4 UFW,
обновления, приватную политику журналов и Docker по явному запросу. Он не
устанавливает VPN, proxy или другие приложения и не открывает их порты.

Каждое приложение размещается в отдельном каталоге `modules/<имя>/` и имеет
свой `install.sh` и README с переменными, портами, способом обновления и
проверкой результата. Модуль запускается только после базового скрипта и от
имени root; для Docker он должен явно требовать работающий daemon.

## Обязательный контракт модуля

1. До изменений определить существующее состояние приложения, его контейнеры,
   конфигурацию и UFW-правила. Повторный запуск должен привести к описанному
   состоянию без дублей, удаления чужих ресурсов или неожиданного restart.
2. Владеть только своими именованными файлами, контейнерами, systemd units и
   firewall-правилами. Не перезаписывать конфигурацию SSH, UFW, Docker daemon,
   sysctl или journald из базового сценария.
3. Открывать только необходимые IPv4-порты и проверять публикацию после
   запуска. Forwarding, NAT и `rp_filter` задаёт VPN-модуль вместе с проверкой
   маршрутизации; база эти параметры не меняет.
4. Не передавать секреты через аргументы команд, обычные логи или общий `/tmp`.
   Использовать файл с правами 0600 либо механизм секретов Docker/systemd.
   В отчёте выводить состояние и безопасную инструкцию получения секрета, но
   не сам секрет или ссылку подключения.
5. Соблюдать базовую политику журналов: не собирать назначения, DNS, действия
   VPN-клиентов и другие данные трафика без отдельного осознанного решения.
   Docker-контейнеры должны использовать ограниченную ротацию логов.
6. После установки проверить состояние службы, слушающие IPv4-порты, firewall,
   сохранение конфигурации после restart и повторный запуск. При ошибке
   остановиться с понятным сообщением и не сообщать ложный успех.

Добавление `user1` в группу `docker` требует отдельного явного выбора при
установке Docker, поскольку доступ к Docker socket равнозначен правам root.
