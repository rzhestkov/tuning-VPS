# Модули проекта

Сейчас в проекте один модуль: `setup_ubuntu_24.04.sh`.

Его назначение — подготовить свежий VPS Ubuntu 24.04 для дальнейшего использования: безопасный SSH-доступ, IPv4 firewall, автоматические обновления, приватная политика журналов, набор административных инструментов и Docker по отдельному запросу. Он не устанавливает приложения и не открывает их порты.

Другие настройки и приложения будут добавляться отдельными модулями после отдельного проектирования.
